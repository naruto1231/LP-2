# LP-2

Bootstrapを使用したサンプルLP(ランディングページ)です。

## 概要

Bootstrapのグリッドシステムをベースにレイアウトを構築し、Lightboxで画像のポップアップ表示を実装したサンプルページです。

## ファイル構成

- `index.html` : ページ本体
- `bootstrap*.css/js` : Bootstrap本体
- `jquery-3.3.1.slim.min.js` : jQuery(slim版)
- `popper.min.js` : Bootstrapのドロップダウン等に必要なPopper.js
- `lightbox*.css/js` : 画像のライトボックス表示用ライブラリ
- 画像素材(`cat-697522__480.png`, `detective-1424831_1280.png`, `presentation-1454403__480.png` など)

## 使用技術

- HTML5
- CSS3
- JavaScript
- Bootstrap
- jQuery
- Lightbox.js
